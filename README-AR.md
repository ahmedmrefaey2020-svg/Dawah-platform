# Dawah دعوة — تركيب نسخة الأندرويد

ارفع كل الملفات دي في جذر مستودع GitHub (من غير مجلدات)، وبعدين Actions ← Build APK ← Run workflow.
الـworkflow بيعمل كل حاجة لوحده: بينسخ ملفات الجافا، وبيضيف الأذونات (الموقع + المنبّه الدقيق + البطارية + الإشعارات) والخدمة والـreceivers، وبيحمّل أذان افتراضي.

> ملاحظة: build-apk.yml لازم يتحط في `.github/workflows/build-apk.yml`.

## تحديث التطبيق من جوه التطبيق
1. شغّل `supabase-admin.sql` مرة واحدة في Supabase (SQL Editor).
2. سجّل دخول في التطبيق بإيميل `dawahplatform2026@gmail.com` ← من القائمة الرئيسية هيظهرلك «لوحة الإدارة».
3. ارفع ملف `index.html` الجديد (واكتب الجديد في التحديث) ← نشر. المستخدمين هتظهرلهم رسالة «تحديث جديد» ويضغطوا تحديث.
- لو التحديث فيه مشكلة وماشتغلش، التطبيق بيرجع تلقائيًا للنسخة المدمجة.
- التحديث ده للواجهة (index.html) فقط. أي تعديل في ملفات الجافا أو الأذونات لازم APK جديد.

## الشكاوى والاقتراحات
بتتبعت على dawahplatform2026@gmail.com (بيفتح تطبيق البريد برسالة جاهزة).

## مكان ملفات الأذان على الجهاز
`/data/data/<appId>/files/adhan/<id>.mp3` + نسخة في IndexedDB. التحميلات (مصحف/أحاديث/تلاوات) في IndexedDB باسم `dawa-dl`.
